# Диалоговая система для Unity

Гибкая модульная диалоговая система с поддержкой анимаций для Unity

## Основные возможности

- Возможность интеграции в **свой проект**
- **Полноценная диалоговая система** с поддержкой ветвления
- **Эффекты анимации**:
    - Постепенное появление (Typewriter effect)
    - Настройка скорости появления текста
    - Плавное появление кнопок
    - Анимация смены изображений персонажей
- Возможность добавить **звук набора текста**
- **Поддержка событий** (старт/конец диалога)
- Наличие **примера использования диалоговой системы**

## Интеграция в проект

1. **Импорт пакета**:
    - Скопируйте папку `Scripts` в свой проект (DialogueTester.cs необязателен)
    - Убедитесь, что есть TextMeshPro (TMP)

2. **Базовая настройка**:
   - Диалог вызывается с помощью вызова метода `StartDialogue(Dialogue dialogue)` у синглетона `DialogueManager.Instance`
   - Также при вызове этого метода активируется событие `OnDialogueStart`, что может быть использовано в вашей логике
    ```csharp
    // Пример вызова диалога:
    public class DialogueTester : MonoBehaviour
    {
        public Dialogue testDialogue;
        private void Start()
        {
            DialogueManager.Instance.StartDialogue(testDialogue);
        }
    }
    ```
   
3. **Настройка UI**
    - Создайте `Panel` (UI -> Panel) на своём `Canvas`, для наглядности можно переименовать в `DialoguePanel`, далее она будет называться именно так
    - Создайте внутри `DialoguePanel` текстовые поля `SpeakerName` и `DialogueText` (UI -> Text - TextMeshPro), Unity предложит импортировать TMP Essentials — соглашаемся
    - Настройте шрифт, размер шрифта, выравнивание и цвет, текст желательно удалить, добавьте `DialogueText` в качестве компонента скрипт `TypewriterEffect.cs`
    - В полях компонента `TypewriterEffect` можете добавить звук печати, если он у вас есть, настроить скорость печати и звук
    - Создайте внутри `DialoguePanel` пустой объект `ChoicesContainer` (Create Empty)
    - Для красивого расположения кнопок можете добавить компоненты `Content Size Fitter` и `Horizontal Layout Group` или `Vertical Layout Group` и настроить их под свой интерфейс
    - Создайте внутри `DialoguePanel` изображение `SpeakerImage` (UI -> Image), добавьте ему в качестве компонента скрипт `FadeImageAnimator.cs`
    - Создайте префаб кнопки: создайте саму кнопку `ChoiceButton` (UI -> Button), затем создайте внутри неё текст (UI -> Text - TextMeshPro), настройте их под свой интерфейс, затем перетащите `ChoiceButton` в папку Prefabs и удалите со сцены
    - Создайте пустой объект `DialogueManager` (CreateEmpty) и добавьте ему в качестве компонента скрипт `DialogueManager.cs`, далее заполните в инспекторе поля менеджера созданными выше объектами и префабом

4. **Создание диалогов**
    - Чтобы создать диалог, кликните правой кнопкой мыши в меню проекта, далее Create -> Dialogue System -> Dialogue
    - В полях созданного диалога создайте новую реплику, нажав на +, и заполните поля `Speaker Name` и `Text`, поле `Speaker Image` заполнять не обязательно
    - В списке `Choices`, нажимая на +, вы можете создавать варианты выбора
    - Для вариантов выбора вы можете добавить диалог, к которому этот выбор приведёт, если этого не сделать, то этот выбор будет завершать диалог
    - Если у реплики нет вариантов выбора, то, при нажатии на единственную кнопку, диалог будет переходить к следующей по списку реплике или завершится, если текущая реплика последняя в списке

## Запуск примера использования

Вы также можете запустить пример использования диалоговой системы и посмотреть, как он реализован. Для этого вам нужно скачать весь проект и открыть его в Unity, а далее запустить сцену `Assets/Scenes/SampleScene.unity`.

## Структура проекта
```
Assets/
├── Scripts/
│   ├── Dialogue.cs              # Базовый ScriptableObject диалога
│   ├── DialogueManager.cs       # Логика диалогов
│   ├── DialogueTester.cs        # Вспомогательный класс для запуска диалогов
│   ├── TypewriterEffect.cs      # Анимация текста
│   ├── FadeImageAnimator        # Анимация изображения
│   └── ButtonAppearAnimator.cs  # Анимация кнопок
├── Prefabs/                     # Префабы
├── Scence/                      # Сцены
├── Sounds/                      # Звуки
└── Dialogues/                   # Примеры диалогов
```
